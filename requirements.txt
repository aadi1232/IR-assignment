# Requirements for Gujarati Spell Checker

# No external dependencies required - uses only Python standard library
# Python 3.6+ is recommended

# The spell checker uses only built-in Python modules:
# - pickle (for dictionary storage)
# - re (for text processing)
# - os (for file operations)
# - collections.Counter (for frequency counting)
# - unicodedata (for text normalization)

# If you want to run in a virtual environment (recommended):
# python -m venv .venv
# source .venv/bin/activate  # On macOS/Linux
# .venv\Scripts\activate     # On Windows

# No pip install required - all modules are built-in!
